# ReAct Agent HLT

A _tool using agent_ built on top of the **ReAct** and **focusedReAct**
paradigms. The project focuses on the implementation of a basic agent capable of
using _search and retrieval_ tools to expand its knowledge if necessary and
Python as a calculator to solve simple arithmetic problems.

## Qwen benchmark

The Qwen2.5-3B-Instruct benchmark (Standard, CoT, ReAct, and Focused ReAct on
HotPotQA and GSM8K), with results, figures, tests, and an interactive trace
viewer, is in [`qwen-benchmark/`](qwen-benchmark/).
